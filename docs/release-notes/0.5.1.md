## English

**IPsec Studio 0.5.1 — compact-mesh identity.** Maintainer: [Rodrigo Immaginario](https://github.com/rodrigoimmaginario).

### What changed
- Approved symbol in the application, site header, browser favicons and Windows executable icon, with light/dark-background variants.
- ICO frames from 16 to 256 px for small and high-DPI use. One vector source and reproducible derived assets, without remote resources or account access.
- Updated PT/EN screenshots and share image. Displayed data is sample data, not a new AD deployment.
- Checks cover mark geometry, distributed files, the native EXE resource and served SVGs. No policy, simulator, compiler or deployment behavior changes.

### Upgrade and Known limitations
- Stop the previous instance, back up settings and `Storage:Root`, and extract into another folder. Preserve plans, journals and evidence; do not overwrite a running process. This visual patch does not change the data format.
- Read-only and empty-domain defaults remain. Windows/RSAT modules and operator permissions are still required; this is neither a shared service nor an automatic policy installer.
- Local gate: 151 Windows tests, required coverage, build/publish, UI, API and native-resource checks. No new AD regression was run for this visual-only change; [0.5.0 evidence and limitations](https://github.com/rodrigoimmaginario/ipsec-studio/blob/v0.5.0/docs/release-notes/0.5.0.md) remain, including resumed runs and the first 68/72 failover with its exact cause unproven. No seamless-availability guarantee or universal production recommendation.
- External pilots, multi-site AD, localized Windows and legacy policies require their own validation. IPsec does not replace firewall/EDR; ESP does not prove encryption and quarantine does not cover every destination/exemption. The package remains unsigned.
- For pre-0.5.0 waves without ownership journals, follow the recovery guide; this patch cannot reconstruct historical memberships.

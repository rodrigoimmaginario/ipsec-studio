## Português

**IPsec Studio 0.4.0** planeja, simula, aplica em ondas, verifica e reverte o isolamento de servidores e de domínio (Server and Domain Isolation) com o IPsec nativo do Windows. A identidade usada é a sua, de administrador.

### Novidades
- **Ondas com aprovação:** a adesão aos grupos de perfil é feita aos poucos, com nota de aprovação obrigatória e registro de cada ação. Se uma onda falhar, a expansão para.
- **Identidade das máquinas:** cada host mostra se o ticket Kerberos já reflete a última mudança de grupo e pode ser renovado na hora.
- **Alterações fora do Studio:** antes de aplicar ou reverter, o Studio confere as GPOs `IpsecStudio-*` e procura outras GPOs com regras IPsec (cerca de 1,4 s para 300 GPOs). Qualquer diferença bloqueia a ação até ser reconhecida.
- **No fio:** a sondagem pode capturar o tráfego e contar os pacotes cifrados (ESP) e as conexões em claro.
- **Saída *Require*** só por opção explícita, com alerta. Por padrão, a saída é *Request*, que não corta o acesso a hosts sem IPsec.
- **Vários controladores de domínio:** gravação no PDC, espera pela replicação e indicação dos DCs pendentes.
- **Reverter** remove as GPOs do Studio e atualiza os hosts.

### Limites conhecidos
- Active Directory com vários sites não foi testado.
- Políticas IPsec antigas (*IP Security Policies*) não são detectadas.
- O alcance de outras GPOs não considera herança bloqueada, vínculo imposto nem filtragem por grupo.
- O pacote não tem assinatura de código.
- O laboratório não substitui um piloto na sua rede: comece por uma onda pequena.

### Requisitos
Estação ou servidor de administração no domínio, com RSAT (módulos ActiveDirectory, GroupPolicy e NetSecurity), e WinRM habilitado nos hosts. O pacote é autocontido: não exige instalar o .NET.

### Conferir o pacote
Compare o SHA-256 do zip com o arquivo `.sha256` publicado junto:

```powershell
Get-FileHash .\ipsec-studio-v0.4.0-win-x64.zip -Algorithm SHA256
```

## English

**IPsec Studio 0.4.0** plans, simulates, applies in waves, verifies and rolls back Server and Domain Isolation with built-in Windows IPsec, using your own administrator identity.

### What's new
- **Waves with approval:** profile-group membership is added step by step, with a required approval note and every action logged; expansion stops if a wave fails.
- **Machine identity:** each host shows whether its Kerberos ticket already reflects the last group change, and can be renewed on the spot.
- **Changes outside the Studio:** before apply or rollback, the Studio checks the `IpsecStudio-*` GPOs and finds other GPOs with IPsec rules (about 1.4 s for 300 GPOs). Any difference blocks the action until it is acknowledged.
- **On the wire:** the probe can capture traffic and count encrypted (ESP) packets and clear connections.
- **Outbound *Require*** only as an explicit option, with a warning; by default outbound is *Request*, which does not cut access to hosts without IPsec.
- **Several domain controllers:** writes on the PDC, wait for replication, pending DCs shown.
- **Rollback** removes the Studio GPOs and refreshes the hosts.

### Known limitations
- Active Directory with several sites has not been tested.
- Legacy IPsec policies (*IP Security Policies*) are not detected.
- The reach of other GPOs ignores blocked inheritance, enforced links and security filtering.
- The package is not code-signed.
- The lab does not replace a pilot on your network: start with a small wave.

### Requirements
A domain-joined administration workstation or server with RSAT (ActiveDirectory, GroupPolicy and NetSecurity modules), and WinRM enabled on the hosts. The package is self-contained: no .NET install needed.

### Check the package
Compare the zip's SHA-256 with the `.sha256` file published next to it:

```powershell
Get-FileHash .\ipsec-studio-v0.4.0-win-x64.zip -Algorithm SHA256
```
